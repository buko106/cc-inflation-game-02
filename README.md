# インフレクエスト

数値が際限なくインフレしていく放置系RPG。スライム相手の「20ダメージ」から始まり、万・億・兆…無量大数を越え、`1e308`（JavaScript の数値の限界）もはるかに突き抜けて `e1万`、`e100万` 桁のダメージを目指します。

ビルド不要。ブラウザだけで動きます。

**▶ プレイ: https://buko106.github.io/cc-inflation-game-02/**
（ユーザーサイトに独自ドメインを設定している場合は `https://<独自ドメイン>/cc-inflation-game-02/` に転送されます）

## 遊び方

`index.html` をブラウザで開くだけで遊べます。ローカルサーバーで開く場合は次のとおりです。

```sh
npm start   # http://localhost:8080
```

- **戦闘**: 勇者は自動で攻撃します。敵をタップ（または `A` キー）すると追撃できます。
- **エリア**: 1エリアは敵9体 + ボス1体。ボスは制限時間内に倒す必要があり、失敗すると「修行モード」（自動進行OFF）になります。強くなったら「ボスに挑む」で再挑戦。◀で前のエリアに戻ったときも修行モードに切り替わります。
- **エリアの特性**: エリアごとに、弱点の属性・耐性のある属性と、「💪強打」（敵の攻撃力×5）や「💚再生」（敵が毎秒最大HPの5%を回復）といった性質があります。ボスに負けたときは、ログに攻略のヒントが出ます。
- **貫通**: 倒した後に余ったダメージは次の敵へ貫通します（1撃で最大100体）。圧倒的に強くなると、1撃で何エリアも吹き飛ばせます。
- **レベル**: 経験値でレベルが上がり、攻撃力・HP・防御力が伸びます。レベル自体も「Lv 1.2e200」のようにインフレします。
- **装備**（ゴールドで強化）: 武器=攻撃力、防具=HP・防御力、装飾品=ゴールド・経験値。10レベルごとに「木の剣 → 銅の剣 → … → 無量大数の剣・改N」と進化し、効果が2倍に跳ね上がります。
- **仲間**（ゴールドで雇用）: 勇者の攻撃力 × 倍率 のダメージを毎秒与えます。25レベルごとに倍率 ×4。仲間には ⚔️物理・🔮魔法・✨神聖 のいずれかの属性があります。村人Aから始まり、「このゲームの作者」「インフレ魔神」…「真・村人A」「超・戦士」と際限なく登場します。新しい仲間に出会えるのはエリアを進めたときだけで、最初の12人はエリア65までに、その後は15エリアごとに1人ずつ増えます（転生すると出会い直し）。後から出会う仲間ほど強く、一覧の上に並びます（先頭は次に雇える仲間）。
- **陣形**（戦闘画面の下、`Q` `W` `E` キー）: 戦わせる仲間の属性を1つ選びます。ほかの属性の仲間は控えに回ります。陣形の属性がエリアの弱点なら仲間の与ダメージが ×10^p、耐性があると ÷10^p になります（p はエリア50ごとに1ずつ増え、エリア500で ×100億）。1つの属性だけを育てると耐性のあるエリアで止まるので、先のエリアを見越して複数の属性を育て、エリアに合わせて陣形を切り替えるのが攻略の鍵です。
- **スキル**（`1`〜`5` キー）: バーサーク、ゴールドラッシュ、時間加速、インフレメテオ、総力戦。到達エリアに応じて解放されます。
- **転生**: エリア20以降で転生できます。レベル・ゴールド・装備・仲間を捨てて「魂」を獲得します。魂1つにつき攻撃力と仲間DPSが+10%。魂を消費して「神々の加護」で永続強化もできます。
- **放置報酬**: ページを閉じていた間（最大12時間）も、いたエリアで戦い続けていたものとして報酬がもらえます。

進行状況はブラウザの localStorage に10秒ごとに自動セーブされます。「記録」タブからセーブデータの書き出し・読み込みができます。

## 構成

| ファイル | 役割 |
| --- | --- |
| `js/bignum.js` | 仮数部と指数部で数値を持つ巨大数クラスと、万・億・兆…の表記 |
| `js/data.js` | エリア・敵・装備・仲間・スキル・転生ボーナスの定義 |
| `js/game.js` | ゲームエンジン（DOM非依存。`tick(dt)` で進行しイベントを発行） |
| `js/ui.js` | 描画・操作・セーブ |
| `tools/simulate.js` | 貪欲に買い物するBotで数時間分をシミュレートし、バランスを確認する |
| `tools/build-single.js` | CSSとJSを埋め込んだ1ファイル版HTMLを `dist/` に出力する |

## 公開（GitHub Pages）

`main` に push すると `.github/workflows/pages.yml` がテストを実行し、`index.html`・`css/`・`js/` だけを GitHub Pages に公開します。Actions タブの「Deploy to GitHub Pages」から手動でも実行できます。

初回のみ、リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にしてください。

## 開発

```sh
npm test            # 巨大数とゲームエンジンのユニットテスト
npm run sim -- 2 4  # 2時間分・秒間4タップでバランスをシミュレート
node tools/build-single.js   # dist/inflation-quest.html を生成
```

シミュレーション（秒間4タップ、Botによる最適化プレイ）での目安:

| | 3属性を育てて陣形を切り替える | 物理の陣形のまま |
| --- | --- | --- |
| `1e308` 突破（エリア300） | 約35分 | 約43分 |
| `e1000` 超え（エリア1000） | 約52分 | 約75分 |

- 最初の壁: 約5〜10分でエリア60前後（敵HP 1e61）
- 転生を重ねるごとに到達エリアが約1.3〜1.5倍に伸びる
- ゴールドの使い道は装備と仲間がおよそ 3:7（陣形を切り替える場合）

バランスの数値は `js/game.js` の `CONFIG` と `js/data.js` にまとまっています。シミュレーターは `SIM_CONFIG` 環境変数で `CONFIG` を上書きして試せます。

```sh
SIM_CONFIG='{"enemyHpGrowth":12}' npm run sim -- 1
SIM_BLIND=1 npm run sim -- 1   # 陣形を物理のまま変えないBot
SIM_SEED=2 npm run sim -- 1    # 乱数の種を変える
```
